Accessibility review

October 1, 2026. Target: WCAG 2.2 AA. This records checks on the local landing page, not a legal certification or complete conformance assessment.

Automated checks

Axe-core 4.13.0: no violations for WCAG A/AA through 2.2 and best-practice rules in desktop light and dark themes, with all FAQs expanded. No violations in the 320px light-theme fixture with WCAG text-spacing overrides (line height 1.5, paragraph spacing 2em, letter spacing .12em, word spacing .16em). Each run passed 40 applicable rules. The QA fixture runs the actual page source and styles; its extra audit scripts are not shipped.

Axe marked decorative illustration text for manual contrast review. The illustration is hidden from assistive technology and repeats no essential content. The caption uses the standard muted text color: 5.56:1 against the light paper and 8.96:1 against the dark paper. Expanded-spacing illustration labels are decorative. No essential text is hidden or clipped.

Manual and structural checks

  • Skip link activated by Enter moves focus to the main landmark.
  • FAQ summary activated by Space expands its answer, keeps focus, and shows a 3px focus outline.
  • Primary navigation, theme selector, and standalone contact links have 44px target heights.
  • One h1, labeled navigation, one main landmark, ordered headings, descriptive logo alternatives, native select and details/summary controls.
  • No horizontal overflow at 320px, including the specified text-spacing overrides. The test caught and fixed a long-heading/grid overflow.
  • All 20 logo assets loaded; HTML nesting, anchors, local assets, domain metadata and Person/FAQ JSON validated.
  • Theme checks pass for system default, saved overrides, reset, unavailable storage, reduced-motion behavior, and unavailable IntersectionObserver.
  • Four-second decorative pulse stops automatically. Reduced-motion CSS disables animation, transitions, reveals, and smooth scrolling. Content is visible without JavaScript.

Limits

Automated rules and the manual checks above cannot prove full accessibility or ADA compliance. A complete VoiceOver/NVDA session, actual browser zoom and OS forced-colors testing, and cross-browser testing have not been completed. Recheck the deployed domain and any future content, forms, embeds, or motion. Accessibility should be maintained as the page changes.

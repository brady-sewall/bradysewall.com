Accessibility

Updated October 1, 2026

I aim to make bradysewall.com usable by people with disabilities, using WCAG 2.2 Level AA as a design and testing target.

Accessibility features

  • Keyboard navigation, a skip link, and visible focus indicators.
  • Descriptive image alternatives and structured headings.
  • Responsive layouts and light, dark, and system themes.
  • Reduced-motion support and a pause/resume control for the hero animation.
  • Accessible controls for optional analytics choices.

Testing and ongoing improvements

The site has been reviewed with automated accessibility tools and manual keyboard and responsive-layout checks. These checks do not establish full conformance or legal certification. Complete assistive-technology and cross-browser testing remains ongoing work. New content and features will need continued review.

Report a barrier

If you have difficulty accessing any part of this website, email hello@bradysewall.com. Please describe the page or feature, the difficulty, and, if comfortable, the browser or assistive technology you used. I will work to provide the information you need and address the issue.
